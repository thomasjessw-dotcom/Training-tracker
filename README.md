# Training Tracker

## Publish with GitHub Pages
1. Create a new public GitHub repository named `training-tracker`.
2. Upload every file in this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select **main** and **/(root)**, then Save.
6. Open the GitHub Pages URL in Safari.
7. Tap **Share → Add to Home Screen**.

The app stores workout data locally on your iPhone. Use Settings → Export backup periodically.
